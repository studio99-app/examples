# Studio99 examples

Working examples for the **Studio99 Indic Typography API**: exact Hindi, Marathi, Gujarati and English text as editable SVG and PNG.

| Example | What it shows |
|---|---|
| [`wedding-invite-nextjs/`](wedding-invite-nextjs) | Next.js app: names typed in English letters become a calligraphy wedding invite, with style picker and SVG download |
| [`shopify-name-preview/`](shopify-name-preview) | Shopify theme snippet + Cloudflare Worker: live calligraphy name preview on personalised products, saved on the order |
| [`curl/`](curl) | Every endpoint from the command line |

All examples keep the API key on a server. None of them puts a key in browser code, and all show results as images rather than inline SVG markup.

Clients: [studio99-node](https://github.com/studio99-app/studio99-node) · [studio99-python](https://github.com/studio99-app/studio99-python) · Spec: [openapi](https://github.com/studio99-app/openapi)
